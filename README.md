# organize-before-writing

文章を書く前に、散らばったメモや会話、調査資料を整理するための日本語のエージェントスキルです。素材を話題ごとにまとめ、重複やつながりを見つけます。構成を頼まれたときは、見出しの順番と各節で扱う内容を提案します。

## 使い方

Codexで使う場合は、`SKILL.md` を作業フォルダの `.agents/skills/organize-before-writing/` に置き、`$organize-before-writing` を選んでください。

- 「このメモを記事にせず、話題ごとに整理して」
- 「この材料でブログの構成を考えて」

元の言葉やニュアンスを保ち、資料にない事実は補いません。本文の執筆や完成原稿の校正だけを頼まれた場合には、このスキルは自動適用しません。
